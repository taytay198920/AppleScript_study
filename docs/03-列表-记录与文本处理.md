# 03 列表、记录与文本处理

## 3.1 列表（list）

```applescript
set emptyList to {}
set nums to {1, 2, 3}
set mixed to {1, "two", 3.0, {4, 5}, true, missing value}
```

⚠️ **索引从 1 开始**，负数表示从末尾倒数：

```applescript
item 1 of nums       --> 1
item 3 of nums       --> 3
item -1 of nums      --> 3（最后一个）
first item of nums   --> 1
last item of nums    --> 3
```

### 取子列表

```applescript
items 2 thru 3 of nums      --> {2, 3}
items 1 thru -2 of nums     --> {1, 2}（去掉最后一个）
rest of nums                --> {2, 3}
```

⚠️ **`butlast` 在纯 AppleScript 里对普通列表不可用**，实测报 `-1728 Can't get butlast of {...}`。
要用「去掉最后一项」，请写 `items 1 thru -2 of lst`。

### 增删改

```applescript
set lst to {1, 2, 3}
set end of lst to 4          --> {1, 2, 3, 4}      （末尾追加，最快）
set beginning of lst to 0    --> {0, 1, 2, 3, 4}   （开头插入，慢，会整体搬移）
set item 2 of lst to 99      --> {0, 99, 2, 3, 4}

set lst to lst & {5, 6}      --> 拼接两个列表
set lst to lst & 7           --> 追加单个元素（自动包成列表）
```

⚠️ **性能陷阱**：循环里用 `set lst to lst & {x}` 是 O(n²)，处理上千条数据会明显变慢。
永远优先 `set end of lst to x`。

### 常用操作

```applescript
count of lst                 --> 元素个数
lst contains "x"             --> 是否包含
reverse of {1, 2, 3}         --> {3, 2, 1}
```

⚠️ **列表没有内置的 sort / filter / map**。三种选择：

**① 手写循环（最通用，无依赖）**

```applescript
on filterList(lst, threshold)
	set kept to {}
	repeat with anItem in lst
		if (contents of anItem) > threshold then set end of kept to (contents of anItem)
	end repeat
	return kept
end filterList
```

⚠️ `repeat with anItem in lst` 里 `anItem` 是**引用**，不是值。要用 `contents of anItem` 取值，
否则后续拼接/比较会出现 `item 1 of {…}` 这样的怪东西。

**② 用 AppleScriptObjC 的 NSSortDescriptor（推荐，实测可用）**

```applescript
use framework "Foundation"
use scripting additions

on sortByKey(lst, keyName, ascending)
	set theArray to current application's NSArray's arrayWithArray:lst
	set theDesc to current application's NSSortDescriptor's sortDescriptorWithKey:keyName ascending:ascending
	set sorted to (theArray's sortedArrayUsingDescriptors:{theDesc})
	return (sorted as list)
end sortByKey

-- 用法（实测）：
-- sortByKey({{mySize:30, tag:"b"}, {mySize:10, tag:"a"}}, "mySize", true)  → {tag:"a", tag:"b"}
-- sortByKey({"banana", "apple", "cherry"}, "self", true)                   → 按字符串本身排序
```

⚠️⚠️ **变量命名致命坑：AppleScript 标识符大小写不敏感。**
不要把变量命名为 `nsArray`、`nsString`、`nsDate`、`nsNumber` 这类和 ObjC 类名**忽略大小写后完全相同**的名字
（`nsDict` 反而没事，因为不存在 `NSDict` 这个类）。
实测 `set nsArray to current application's NSArray's arrayWithArray:lst` 会报
`nsArray doesn't understand the "arrayWithArray_" message (-1708)` —— 因为 `NSArray` 被解析成了你那个局部变量。
改名成 `theArray` / `cocoaList` 即可正常工作。

**③ 借 Shell 排序（简单但要注意换行与转义）**

```applescript
on sortLines(theText)
	return do shell script "sort <<'EOS'
" & theText & "
EOS"
end sortLines
```

⚠️ 用 heredoc（`<<'EOS'`）而不是把内容拼进命令行，可以避免引号注入问题。
但内容里如果本身包含 `EOS` 就会出错，正式代码建议改用临时文件。

## 3.2 记录（record）

```applescript
set person to {name:"Taylor", age:30, tags:{"a", "b"}}

name of person           --> "Taylor"
person's age             --> 30
tags of person           --> {"a", "b"}
count of person          --> 3（字段数）
```

### 遍历记录

AppleScript 不能直接 `repeat with k in rec`。两种实用办法：

```applescript
-- 办法 1：直接列已知字段（最简单）
set vals to {name of person, age of person}

-- 办法 2：用 AppleScriptObjC 拿到键名（实测可用）
use framework "Foundation"
use scripting additions          -- ⚠️ 必须加，否则 current date 等全部失效

on recordKeys(rec)
	set theDict to current application's NSDictionary's dictionaryWithDictionary:rec
	set theKeys to (theDict's allKeys()) as list
	set outKeys to {}
	repeat with k in theKeys
		set end of outKeys to (k as text)
	end repeat
	return outKeys
end recordKeys
```

⚠️⚠️ **`name` 这个键在桥接到 NSDictionary 时会被丢掉！** 实测：

| 记录字面量 | `allKeys` 结果 |
| --- | --- |
| `{name:"T", age:30, city:"SH"}` | `{"age", "city"}` ← `name` 消失 |
| `{firstName:"T", age:30, city:"SH"}` | `{"firstName", "age", "city"}` |
| `{&#124;name&#124;:"T", age:30}` | `{"name", "age"}` ← 用竖线转义就保住了 |

原因是 `name` 被当成了 AppleScript 的标准属性而不是普通字典键。
**建议：给记录起键名时避开 `name`、`id`、`class`、`text`、`URL` 这些标准属性名**；
非要用就写成 `{|name|:"T"}`。

⚠️ 记录字段名如果和 AppleScript 保留字冲突（如 `class`），一律用竖线转义：`{|class| of rec}`。

⚠️ **记录的键在编译期解析**，不能用变量当键名：

```applescript
set k to "name"
k of person          -- ❌ 编译错误
```

要动态取键，只能走 AppleScriptObjC：

```applescript
use framework "Foundation"
use scripting additions

on valueForKey(rec, keyName)
	set theDict to current application's NSDictionary's dictionaryWithDictionary:rec
	set v to (theDict's valueForKey:keyName)
	if v is missing value then return missing value
	return v as text
end valueForKey
```

## 3.3 文本处理：`text item delimiters`

这是 AppleScript 字符串处理的核心机制，也是最容易出错的地方。

```applescript
-- 切分
set AppleScript's text item delimiters to "/"
set parts to text items of "a/b/c"       --> {"a", "b", "c"}
set secondPart to text item 2 of "a/b/c" --> "b"
set AppleScript's text item delimiters to ""

-- 拼接
set AppleScript's text item delimiters to ", "
set joined to {"a", "b", "c"} as text    --> "a, b, c"
set AppleScript's text item delimiters to ""
```

⚠️⚠️ **三条铁律**：

1. `text item delimiters` 是**全局状态**，会影响整个脚本（包括你调用的库）。
   用完**必须**立刻还原成 `""`。
2. 忘记还原会导致后续莫名其妙的字符串错误，极难排查。
3. 分隔符可以是**多个字符的列表**，会按任意一个切分：

```applescript
set AppleScript's text item delimiters to {",", ";", " "}
text items of "a,b;c d"     --> {"a", "b", "c", "d"}
set AppleScript's text item delimiters to ""
```

### 推荐：封装成函数，避免全局状态泄漏

```applescript
on splitText(theText, theDelimiter)
	set oldDelims to AppleScript's text item delimiters
	set AppleScript's text item delimiters to theDelimiter
	set theParts to text items of theText
	set AppleScript's text item delimiters to oldDelims
	return theParts
end splitText

on joinText(theList, theDelimiter)
	set oldDelims to AppleScript's text item delimiters
	set AppleScript's text item delimiters to theDelimiter
	set theText to theList as text
	set AppleScript's text item delimiters to oldDelims
	return theText
end joinText

on replaceText(theText, searchFor, replaceWith)
	return my joinText(my splitText(theText, searchFor), replaceWith)
end replaceText
```

⚠️ `joinText` 对空列表返回 `""`，对非文本元素会自动强制转换（`{1, 2} as text` → `"12"`）。

## 3.4 取子串

```applescript
set s to "AppleScript"

length of s              --> 11（等价于 count of s）
text 1 thru 5 of s       --> "Apple"（含首含尾）
text 2 thru 5 of s       --> "pple"
text 7 thru -1 of s      --> "cript"
text -1 thru -3 of s     --> "tpi"（倒序！）
character 3 of s         --> "p"
first character of s     --> "A"
last character of s      --> "t"
```

⚠️ `thru` 是**闭区间**（两端都包含），和大多数语言的切片语义不同。

⚠️ 倒着写 `text -1 thru -3` 会得到**反转**的子串，不是你以为的「倒数第 3 到倒数第 1」。

### 按分隔符取第 N 段（比切分整个字符串快）

```applescript
set AppleScript's text item delimiters to "."
set ext to text item -1 of "photo.backup.tar.gz"   --> "gz"
set baseName to text 1 thru text item -2 of "photo.backup.tar.gz"
set AppleScript's text item delimiters to ""
```

## 3.5 没有内置的 upper / lower

⚠️ AppleScript **没有** `uppercase`/`lowercase` 命令。实测 `uppercase of "x"` 报错
`-1700 Can't make uppercase of "hello world" into type Unicode text`。

三种替代方案：

```applescript
-- 方案 1：AppleScriptObjC（推荐，无外部进程开销）
use framework "Foundation"
use scripting additions

on toUpper(s)
	return ((current application's NSString's stringWithString:s)'s uppercaseString()) as text
end toUpper

on toLower(s)
	return ((current application's NSString's stringWithString:s)'s lowercaseString()) as text
end toLower

on capitalize(s)
	return ((current application's NSString's stringWithString:s)'s capitalizedString()) as text
end capitalize
```

```applescript
-- 方案 2：Shell（简单但有进程开销 + 转义风险）
do shell script "printf '%s' " & quoted form of s & " | tr '[:lower:]' '[:upper:]'"
```

```applescript
-- 方案 3：纯 AppleScript 手写（无依赖，适合只用 ASCII）
on toUpperASCII(s)
	set chars to characters of s
	repeat with i from 1 to count of chars
		set c to item i of chars
		if c is in {"a","b","c","d","e","f","g","h","i","j","k","l","m","n","o","p","q","r","s","t","u","v","w","x","y","z"} then
			set item i of chars to (character id ((id of c) - 32))
		end if
	end repeat
	set AppleScript's text item delimiters to ""
	return chars as text
end toUpperASCII
```

## 3.6 字符与编码

```applescript
id of "A"              --> 65
character id 65        --> "A"
characters of "abc"    --> {"a", "b", "c"}
```

⚠️ `id of` 返回的是 Unicode 码点，不是旧版的 ASCII（但对 ASCII 范围内两者一致）。

## 3.7 其他实用文本操作

```applescript
offset of "Scr" in "AppleScript"     --> 6（找不到返回 0）
quoted form of "/tmp/a b.txt"        --> "'/tmp/a b.txt'"（用于 shell 命令）
```

⚠️ `offset` 是 Standard Additions 命令，在 `tell` 块里要加 `my` 或移出 tell 块，
否则会被当成发给 App 的命令而报错。

### 数字补零

AppleScript 没有 `printf`，补零要手写：

```applescript
on padLeft(n, width)
	set s to (n as integer) as text
	repeat while (length of s) < width
		set s to "0" & s
	end repeat
	return s
end padLeft

padLeft(7, 2)     --> "07"
padLeft(42, 4)    --> "0042"
```

### 去除首尾空白

```applescript
on trimText(s)
	set ws to {" ", tab, linefeed, return}
	set chars to characters of s
	repeat while (count of chars) > 0 and (item 1 of chars) is in ws
		set chars to rest of chars
	end repeat
	repeat while (count of chars) > 0 and (item -1 of chars) is in ws
		set chars to item 1 thru -2 of chars
	end repeat
	set AppleScript's text item delimiters to ""
	return chars as text
end trimText
```

⚠️ 用 `characters of` + 列表操作处理长字符串很慢（O(n²)）。
大文本优先用 AppleScriptObjC 的 `NSString's stringByTrimmingCharactersInSet:`，或交给 Shell。
