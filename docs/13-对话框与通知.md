# 13 对话框与通知

全部来自 Standard Additions，参数签名取自本机 `sdef`，均实测。

## 13.1 display dialog

```applescript
set theReply to display dialog "确定要删除这 3 个文件吗？" ¬
	buttons {"取消", "删除"} ¬
	default button "删除" ¬
	cancel button "取消" ¬
	with title "确认操作" ¬
	with icon caution

button returned of theReply     --> "删除"
```

### 完整参数（sdef 原文）

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| （直接参数） | text | 对话框正文 |
| `default answer` | text | 加上就有输入框，这里是默认值 |
| `hidden answer` | boolean | 输入内容显示为圆点（密码框） |
| `buttons` | list of text | ⚠️ **最多 3 个按钮** |
| `default button` | text / integer | 默认按钮（名字或序号，回车触发） |
| `cancel button` | text / integer | 取消按钮（Esc 触发，点了会抛 -128） |
| `with title` | text | 窗口标题 |
| `with icon` | `stop` / `note` / `caution` / integer / file | 图标 |
| `giving up after` | integer | N 秒后自动关闭，**0 或不写 = 永不超时** |

### 返回值

```applescript
-- 无输入框时
{button returned:"删除", gave up:false}

-- 有 default answer 时多一个 text returned
{button returned:"好", text returned:"用户输入", gave up:false}

-- 超时自动关闭时
{button returned:"", gave up:true}
```

⚠️⚠️ **`giving up after 0` 表示「永不超时」，不是「立刻关闭」。**
实测写成 0 会让脚本永久阻塞在那里等人点按钮。要测试自动关闭请写 `giving up after 1`。

### 密码输入

```applescript
set pwReply to display dialog "请输入密码" default answer "" hidden answer true ¬
	buttons {"取消", "确定"} default button "确定" cancel button "取消"
set thePassword to text returned of pwReply
```

⚠️ 拿到的密码是明文 text，**不要写进日志、不要存到脚本的 property 里**
（property 会被编译进 `.scpt`/`.app` 文件持久保存）。用完立刻 `set thePassword to ""`。

### 取消处理

```applescript
try
	set theReply to display dialog "继续？" buttons {"取消", "继续"} cancel button "取消"
on error number errNum
	if errNum is -128 then
		log "用户取消"
		return
	end if
	error number errNum
end try
```

⚠️ 只有指定了 `cancel button` 的按钮被点击时才抛 -128。
如果不指定 `cancel button`，系统会自动把最左边的按钮当取消按钮（在有 2 个以上按钮时）。

## 13.2 display alert

`display alert` 比 `display dialog` 更适合「重要提示」，外观是系统标准警告样式，
并且**可以指定由哪个 App 弹出**（对话框会归属那个 App）：

```applescript
set theReply to display alert "无法完成备份" ¬
	message "目标磁盘空间不足，需要额外 2.3 GB。" ¬
	as critical ¬
	buttons {"知道了", "重试"} ¬
	default button "重试" ¬
	cancel button "知道了"

button returned of theReply
```

| 参数 | 说明 |
| --- | --- |
| （直接参数） | 标题（粗体大字） |
| `message` | 详细说明 |
| `as` | `information` / `warning` / `critical` |
| `buttons` | 按钮列表 |
| `default button` | 默认按钮 |
| `cancel button` | 取消按钮 |
| `giving up after` | N 秒后自动关闭 |

⚠️ 在 `tell application "X"` 块里调用 `display alert`，弹框会显示为 X 的图标和名字。
在 `osascript` 里调用则显示为「osascript」。

## 13.3 display notification（不阻塞）

```applescript
display notification "备份已完成，共 128 个文件" ¬
	with title "每日备份" ¬
	subtitle "2026-11-17 09:00" ¬
	sound name "Glass"
```

| 参数 | 说明 |
| --- | --- |
| （直接参数） | 正文，**可选** |
| `with title` | 标题 |
| `subtitle` | 副标题 |
| `sound name` | 系统提示音名称（如 `Glass`、`Ping`、`Submarine`） |

⚠️ 重要限制：

- **不会阻塞脚本**，发完就返回，这点和 `display dialog` 完全不同。
- **拿不到用户是否点击了通知**。要交互必须用 `display dialog`。
- 通知的「发送者」显示为运行脚本的宿主（`osascript` 或你的 applet）。
  在「系统设置 → 通知」里可以为它配置横幅/提醒样式、是否允许。
- ⚠️ 如果用户在系统设置里关掉了该宿主的通知权限，这条调用**静默失败，不报错**。
  不要用它做关键提示。
- 专注模式（勿扰）下通知会被压制。

可用的提示音名称（本机 `/System/Library/Sounds/` 实测，macOS 26.6）：

```
Basso Blow Bottle Frog Funk Glass Hero Morse Ping Pop Purr Sosumi Submarine Tink
```

用户自定义的音效放在 `~/Library/Sounds/`，同样可以用名字引用。
传一个不存在的名字不会报错，只是静音。

## 13.4 文件/文件夹选择器

```applescript
-- 选文件
set theFile to choose file with prompt "选择要处理的文件"

-- 限定类型（推荐用 UTI，扩展名在旧系统上更通用）
set theFile to choose file with prompt "选择图片" of type {"public.image"}
set theFile to choose file with prompt "选择表格" of type {"public.comma-separated-values-text", "xlsx"}

-- 多选
set theFiles to choose file with prompt "选择多个文件" with multiple selections allowed

-- 显示隐藏文件 / 指定起始目录
set theFile to choose file default location (path to desktop folder) with invisibles

-- 选文件夹
set theFolder to choose folder with prompt "选择输出目录"

-- 保存对话框（选一个"还不存在"的文件名）
set newFile to choose file name with prompt "保存为" default name "报告.txt" ¬
	default location (path to documents folder)
```

| 命令 | 返回类型 | 文件需已存在 |
| --- | --- | --- |
| `choose file` | alias（多选时是 alias 列表） | ✅ 必须存在 |
| `choose folder` | alias | ✅ 必须存在 |
| `choose file name` | **file**（不是 alias） | ❌ 可以不存在 |

⚠️ `choose file name` 返回的是 `file` 类型，**不能直接 `as alias`**（文件还不存在）。
要路径用 `POSIX path of newFile`。

⚠️ 这三个命令用户点「取消」都会抛 **-128**。

⚠️ 它们都是**阻塞式模态窗口**，且没有 `giving up after` 参数。
在无人值守的定时任务里**绝对不能用**，脚本会永远卡住。

### 统一处理取消

```applescript
on chooseFileSafe(promptText)
	try
		return choose file with prompt promptText
	on error number errNum
		if errNum is -128 then return missing value
		error number errNum
	end try
end chooseFileSafe
```

## 13.5 choose from list

```applescript
set theChoice to choose from list {"开发", "测试", "生产"} ¬
	with title "选择环境" ¬
	with prompt "要部署到哪个环境？" ¬
	default items {"测试"} ¬
	OK button name "部署" ¬
	cancel button name "算了" ¬
	with multiple selections allowed ¬
	without empty selection allowed

if theChoice is false then
	-- ⚠️ 用户取消时返回 false，不是抛错！
	return
end if

set AppleScript's text item delimiters to ", "
log theChoice as text
set AppleScript's text item delimiters to ""
```

⚠️⚠️ **`choose from list` 的取消行为和其他对话框不同**：

- 用户点确定 → 返回**列表**（即使只选了一项）
- 用户点取消 → 返回 **`false`**（布尔值），**不抛 -128**

所以必须 `if theChoice is false then`，不能用 `try`。

⚠️ 列表元素可以是 text 或 number，但混用时行为不稳定，建议统一转成 text。

## 13.6 其他交互命令

```applescript
choose color                                  --> {0, 32896, 65535}（0-65535 的 RGB）
choose color default color {65535, 0, 0}

choose application with prompt "选择要控制的 App"
choose URL                                      -- 已废弃，新系统上可能不可用

beep                                            -- 系统提示音
beep 2                                          -- 响两声

say "任务已完成"                                 -- 语音播报
say "Hello" using "Alex"

set volume output volume 30                     -- 设置音量 0-100
get volume settings                             --> 含 4 个字段的记录（实测）
-- output volume:52, input volume:…, alert volume:…, output muted:false

system attribute "USER"                         --> "taylor"（可读任意 shell 环境变量）
```

### 颜色值转换

`choose color` 返回 0–65535 范围，和 CSS 的 0–255 差 257 倍：

```applescript
on rgb256To16(rgbList)
	set out to {}
	repeat with c in rgbList
		set end of out to ((contents of c) * 257)
	end repeat
	return out
end rgb256To16

on rgb16To256(rgbList)
	set out to {}
	repeat with c in rgbList
		set end of out to ((contents of c) div 257)
	end repeat
	return out
end rgb16To256
```

## 13.7 无人值守场景的注意事项

| 命令 | 无人值守可用？ |
| --- | --- |
| `display notification` | ✅ 可用（但用户可能看不到） |
| `display dialog … giving up after N` | ⚠️ 勉强可用，N 秒后自动继续 |
| `display dialog`（无 giving up after） | ❌ 永久阻塞 |
| `display alert`（无 giving up after） | ❌ 永久阻塞 |
| `choose file` / `choose folder` / `choose from list` | ❌ 永久阻塞 |
| `do shell script … with administrator privileges` | ❌ 无法弹密码框 |
| `say` / `beep` | ✅ 可用 |

⚠️ **定时任务/后台脚本里，所有会弹交互窗口的命令都必须有超时或完全避免。**
参数应从配置文件、命令行参数或环境变量读取，而不是问用户。

推荐模式：脚本支持两种运行方式

```applescript
on run argv
	if (count of argv) > 0 then
		-- 无人值守：参数从命令行来
		set targetPath to item 1 of argv
	else
		-- 交互模式：弹窗让用户选
		set targetFolder to choose folder with prompt "选择目录"
		set targetPath to POSIX path of targetFolder
	end if
	my doWork(targetPath)
end run
```
