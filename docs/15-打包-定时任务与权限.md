# 15 打包、定时任务与权限

## 15.1 编译成可执行文件

### osacompile

```bash
# 编译成 .scpt（加载更快，源码仍在里面）
osacompile -o myscript.scpt myscript.applescript

# 编译成普通 applet（双击运行一次就退出）
osacompile -o MyApp.app myscript.applescript

# 编译成 stay-open applet（常驻，支持 on idle / on quit）
osacompile -s -o MyDaemon.app myscript.applescript

# 编译成 execute-only（源码不可见，防偷看，⚠️ 也无法再反编译调试）
osacompile -x -o Secret.scpt myscript.applescript

# 带启动画面
osacompile -s -u -o MyApp.app myscript.applescript
```

完整选项：

| 选项 | 作用 |
| --- | --- |
| `-o name` | 输出路径（后缀决定格式：`.scpt` / `.app`） |
| `-s` | stay-open applet（配合 `on idle`） |
| `-u` | 显示启动画面 |
| `-x` | execute-only（不含可读源码） |
| `-l language` | 指定语言（默认 AppleScript，可写 `JavaScript`） |
| `-e command` | 直接给一行源码，可多个 |

⚠️ `osacompile` 输出 `.app` 时会打印 `.: replacing existing signature` —— 这是正常的重新签名提示，不是错误。

### 反编译回文本

```bash
osadecompile myscript.scpt > myscript.applescript
```

⚠️ `-x` 编译的 execute-only 脚本无法反编译。

⚠️ 反编译出来的代码**注释会丢失**，`property` 的当前值会被写死成上次运行时的值。
源码请始终以 `.applescript` 纯文本为准，纳入版本控制。

## 15.2 App Bundle 结构

`osacompile -o X.app` 生成的是标准 macOS app bundle：

```
MyApp.app/
├── Contents/
│   ├── Info.plist              ← 可改：图标名、是否显示在 Dock
│   ├── MacOS/                  ← applet 可执行文件
│   ├── PkgInfo
│   ├── Resources/
│   │   ├── Scripts/main.scpt   ← ⚠️ 编译后的脚本在这里
│   │   ├── applet.icns         ← 图标
│   │   └── …
│   └── _CodeSignature/
```

### 换图标

```bash
# 用 png 生成 icns
mkdir icon.iconset
sips -z 16 16     icon.png --out icon.iconset/icon_16x16.png
sips -z 32 32     icon.png --out icon.iconset/icon_16x16@2x.png
sips -z 128 128   icon.png --out icon.iconset/icon_128x128.png
sips -z 256 256   icon.png --out icon.iconset/icon_128x128@2x.png
sips -z 512 512   icon.png --out icon.iconset/icon_512x512.png
iconutil -c icns icon.iconset -o applet.icns
cp applet.icns MyApp.app/Contents/Resources/applet.icns
touch MyApp.app     # 刷新 Finder 图标缓存
```

### 隐藏 Dock 图标（做菜单栏/后台工具）

在 `MyApp.app/Contents/Info.plist` 里加：

```xml
<key>LSUIElement</key>
<true/>
```

```bash
/usr/libexec/PlistBuddy -c "Add :LSUIElement bool true" MyApp.app/Contents/Info.plist
```

⚠️ 改动 Info.plist 会破坏代码签名，可能需要重新签名：

```bash
codesign --force --deep --sign - MyApp.app
```

## 15.3 定时任务：launchd（推荐）

⚠️ **不要用 `cron`**。macOS 上 cron 已被 launchd 取代，
在睡眠期间不会补跑，且拿不到 GUI 会话权限。

### 最小配置

`~/Library/LaunchAgents/com.example.mytask.plist`：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.example.mytask</string>

    <key>ProgramArguments</key>
    <array>
        <string>/usr/bin/osascript</string>
        <string>/Users/taylor/scripts/daily-backup.applescript</string>
    </array>

    <!-- 每 5 分钟跑一次 -->
    <key>StartInterval</key>
    <integer>300</integer>

    <key>StandardOutPath</key>
    <string>/tmp/com.example.mytask.log</string>
    <key>StandardErrorPath</key>
    <string>/tmp/com.example.mytask.err</string>
</dict>
</plist>
```

### 每天固定时间跑

把 `StartInterval` 换成 `StartCalendarInterval`：

```xml
<key>StartCalendarInterval</key>
<dict>
    <key>Hour</key><integer>9</integer>
    <key>Minute</key><integer>0</integer>
    <key>Weekday</key><integer>1</integer>   <!-- 0/7=周日, 1=周一 … 6=周六；省略表示每天 -->
</dict>
```

多个时间点用数组：

```xml
<key>StartCalendarInterval</key>
<array>
    <dict><key>Hour</key><integer>9</integer><key>Minute</key><integer>0</integer></dict>
    <dict><key>Hour</key><integer>18</integer><key>Minute</key><integer>30</integer></dict>
</array>
```

### 安装与管理

```bash
# 语法检查（必做）
plutil -lint ~/Library/LaunchAgents/com.example.mytask.plist

# 加载（现代语法，推荐）
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.example.mytask.plist

# 卸载
launchctl bootout gui/$(id -u)/com.example.mytask

# 立即触发一次（调试用）
launchctl kickstart -k gui/$(id -u)/com.example.mytask

# 查看状态
launchctl print gui/$(id -u)/com.example.mytask
launchctl list | grep com.example

# 旧语法（仍可用）
launchctl load -w ~/Library/LaunchAgents/com.example.mytask.plist
launchctl unload ~/Library/LaunchAgents/com.example.mytask.plist
```

⚠️ `Label` 必须和文件名（去掉 `.plist`）一致，且全局唯一。改了 plist 必须先 `bootout` 再 `bootstrap`。

### LaunchAgents vs LaunchDaemons

| | LaunchAgents | LaunchDaemons |
| --- | --- | --- |
| 路径 | `~/Library/LaunchAgents/`（当前用户）<br>`/Library/LaunchAgents/`（所有用户） | `/Library/LaunchDaemons/` |
| 运行身份 | 登录用户 | root |
| 何时运行 | **用户登录后** | 开机即运行 |
| 能弹窗/GUI | ✅ 可以 | ❌ 不能 |
| 适用 | 个人自动化（绝大多数场景） | 系统级服务 |

⚠️ **AppleScript 自动化几乎总是用 LaunchAgent**。LaunchDaemon 没有 GUI 会话，
`display dialog`、`choose file`、UI Scripting 全部失效。

### ⚠️ launchd 环境的坑

1. **PATH 极简**：只有 `/usr/bin:/bin:/usr/sbin:/sbin`。Homebrew 等工具要写绝对路径。
2. **没有交互式 shell 的环境变量**：`.zshrc` 里的 export 全都不生效。
3. **权限弹窗可能出不来**：TCC 授权框需要有活跃的 GUI 会话。
   如果脚本卡在权限请求上，会静默失败。
4. **`StandardOutPath` 目录必须已存在**且可写。
5. **首次运行会被 Gatekeeper/TCC 拦**：先手动跑一次 `osascript xxx.applescript`
   把权限授好，再装 launchd。
6. **睡眠期间错过的任务**：`StartCalendarInterval` 会在唤醒后补跑一次；
   `StartInterval` 不会累积补跑。

调试模板（把环境信息打出来）：

```applescript
-- env-probe.applescript
on run
	set envInfo to do shell script "echo PATH=$PATH; echo HOME=$HOME; echo USER=$USER; whoami; pwd"
	set logPath to "/tmp/launchd-probe.log"
	set fh to open for access (POSIX file logPath) with write permission
	write ((current date) as string) & linefeed & envInfo & linefeed & "---" & linefeed ¬
		to fh starting at eof as «class utf8»
	close access fh
end run
```

## 15.4 权限体系（TCC）总览

这是 macOS 自动化最容易翻车的地方。**报错本身常常不告诉你是权限问题。**

| 权限 | 系统设置路径 | 什么时候需要 | 典型报错 |
| --- | --- | --- | --- |
| **自动化** | 隐私与安全性 → 自动化 | `tell application "其他App"` | `-1743`、`Not authorized to send Apple events to X` |
| **辅助功能** | 隐私与安全性 → 辅助功能 | UI Scripting、`keystroke`、`key code` | `-25211`、`assistive access is not allowed` |
| **完全磁盘访问** | 隐私与安全性 → 完全磁盘访问权限 | 读 Mail/Messages/Safari 数据、`~/Library` 下某些目录 | `-1743`、`-120`、返回空数据 |
| **文件与文件夹** | 隐私与安全性 → 文件与文件夹 | 访问桌面/文稿/下载/可移动卷 | `-1743`、`-120` |
| **日历** | 隐私与安全性 → 日历 | Calendar / Reminders | `-1743` |
| **通讯录** | 隐私与安全性 → 通讯录 | Contacts | `-1743` |
| **照片** | 隐私与安全性 → 照片 | Photos | `-1743` |
| **通知** | 通知 | `display notification` | 静默失败，不报错 |
| **App 管理** | 隐私与安全性 → App 管理 | 用脚本改别的 App | `-1743` |

### ⚠️ 关键概念：权限授予的是「宿主程序」

TCC 授权的对象是**发起调用的那个可执行程序**，不是你的脚本文件。

| 运行方式 | 需要授权的程序 |
| --- | --- |
| 终端里 `osascript x.applescript` | 你的终端 App（Terminal / iTerm / Warp） |
| Script Editor 里 ⌘R | Script Editor |
| 编译成 `MyApp.app` 双击 | MyApp.app |
| launchd 调 `/usr/bin/osascript` | `osascript`（且常需给终端或 launchd 上下文授权） |
| Automator / 快捷指令 | 对应宿主 |

**实践含义**：你在终端里调好了权限，把同一个脚本编译成 `.app` 后**要重新授权一遍**。

### 授权流程

1. 第一次执行到需要权限的操作时，系统弹框「XXX 想要控制 YYY」→ 点「好」
2. 如果弹框没出现或点错了，手动去：**系统设置 → 隐私与安全性 → 自动化**，
   找到宿主程序，展开后勾选目标 App
3. 辅助功能类权限要手动把宿主程序**拖进列表**（点 `+` 号添加）
4. 改完权限**必须完全退出并重启宿主程序**（⌘Q，不是关窗口）

### 权限被拒绝后的恢复

```bash
# 查看/重置某个程序的 TCC 记录
tccutil reset AppleEvents com.apple.Terminal
tccutil reset Accessibility com.apple.Terminal
tccutil reset All com.example.myapp
```

⚠️ `tccutil reset` 之后下次运行会重新弹授权框，是修复「点了不允许再也弹不出来」的标准手段。

### 检测权限是否就绪（脚本自检）

```applescript
on checkPermissions()
	set report to {}

	-- 辅助功能
	tell application "System Events"
		set end of report to "辅助功能: " & (UI elements enabled as text)
	end tell

	-- 自动化（试探性调用 Finder）
	try
		tell application "Finder" to get name of startup disk
		set end of report to "控制 Finder: true"
	on error errMsg number errNum
		set end of report to "控制 Finder: false (#" & errNum & ") " & errMsg
	end try

	set AppleScript's text item delimiters to linefeed
	return report as text
end checkPermissions
```

## 15.5 分发脚本给别人

| 方式 | 优点 | 缺点 |
| --- | --- | --- |
| `.applescript` 纯文本 | 可读、可 diff、体积小 | 对方要装/会用 osascript |
| `.scpt` | 加载快 | 仍可反编译 |
| `.app` applet | 双击即用 | Gatekeeper 可能拦；权限要重新授 |
| execute-only `.scpt` | 隐藏源码 | 无法调试，也拦不住有心人 |
| 打包成 `.pkg` / `.dmg` | 专业分发 | 需要开发者证书做签名和公证 |

⚠️ **未签名的 `.app` 在别人机器上会被 Gatekeeper 拦**。
临时绕过：右键 → 打开，或

```bash
xattr -dr com.apple.quarantine /path/to/MyApp.app
```

正式分发需要 Apple Developer ID 证书签名 + 公证（notarization）：

```bash
codesign --force --deep --options runtime --sign "Developer ID Application: Your Name (TEAMID)" MyApp.app
xcrun notarytool submit MyApp.zip --apple-id you@example.com --team-id TEAMID --password APP_SPECIFIC_PWD --wait
xcrun stapler staple MyApp.app
```

## 15.6 stay-open applet 实战模板

```applescript
-- 每 30 秒检查一次，可被优雅退出
property checkInterval : 30
property logPath : missing value

on run
	set logPath to (POSIX path of (path to home folder)) & "Library/Logs/MyDaemon.log"
	my logMsg("启动")
end run

on idle
	try
		my doWork()
	on error errMsg number errNum
		my logMsg("错误 #" & errNum & ": " & errMsg)
	end try
	return checkInterval
end idle

on doWork()
	-- 实际逻辑
	my logMsg("执行了一次检查")
end doWork

on logMsg(msg)
	if logPath is missing value then return
	set stamp to (current date) as string
	try
		set fh to open for access (POSIX file logPath) with write permission
		write (stamp & "  " & msg & linefeed) to fh starting at eof as «class utf8»
		close access fh
	end try
end logMsg

on quit
	my logMsg("退出")
	continue quit
end quit
```

编译：`osacompile -s -o MyDaemon.app daemon.applescript`

⚠️ 必须加 `-s`，否则 `on idle` 不会被调用。

⚠️ `on idle` 的第一次调用发生在 applet 启动后约 `checkInterval` 秒，
要立即执行一次请在 `on run` 里也调用 `my doWork()`。
