# 01 环境与运行方式

## 1.1 macOS 自带的工具链

macOS 不需要安装任何东西，以下工具开箱即用：

| 工具 | 路径 | 用途 |
| --- | --- | --- |
| `osascript` | `/usr/bin/osascript` | 命令行执行脚本，自动化脚本的主力 |
| `osacompile` | `/usr/bin/osacompile` | 把源码编译成 `.scpt` 或 `.app` |
| `osadecompile` | `/usr/bin/osadecompile` | 把编译好的 `.scpt` 还原成文本源码 |
| `osalang` | `/usr/bin/osalang` | 列出已安装的 OSA 语言 |
| `sdef` | `/usr/bin/sdef` | 导出某个 App 的脚本术语字典（**极其重要**） |
| 脚本编辑器 | `/System/Applications/Utilities/Script Editor.app` | GUI 编辑、编译、查字典 |
| 自动化 | `/System/Applications/Automator.app` | 可视化流程，可导出 AppleScript |

```bash
osalang
# AppleScript
# JavaScript                ← JXA，见 docs/16
# Generic Scripting System
```

## 1.2 文件后缀与格式

| 后缀 | 说明 |
| --- | --- |
| `.applescript` / `.as` | 纯文本源码，推荐用于版本控制 |
| `.scpt` | 已编译脚本（二进制，含源码），加载比纯文本快 |
| `.scptd` | 脚本 bundle（可带辅助资源文件） |
| `.app` | applet / droplet，可双击运行，也能拖文件进去 |

纯文本源码 ↔ 编译脚本互转：

```bash
osacompile -o myscript.scpt myscript.applescript    # 文本 → 编译
osadecompile myscript.scpt > myscript.applescript  # 编译 → 文本
```

## 1.3 osascript 的四种喂脚本方式

```bash
# ① 单行 -e
osascript -e 'return 1 + 1'

# ② 多个 -e 拼成多行（推荐用于短脚本）
osascript -e 'set x to 5' -e 'return x * 2'

# ③ 指定脚本文件
osascript myscript.applescript
osascript myscript.scpt

# ④ 标准输入（注意：要传参数必须显式写 "-"）
echo 'return "from stdin"' | osascript -
```

⚠️ **多个 `-e` 会被拼成一个脚本**，所以中间出现 `return` 会直接结束整个脚本：

```bash
osascript -e 'return "第一句"' -e 'return "第二句"'
# 只输出：第一句
```

## 1.4 向脚本传命令行参数

脚本里用 `on run argv` 接收，`argv` 是一个**字符串列表**：

```applescript
-- hello.applescript
on run argv
    if (count of argv) is 0 then return "没有参数"
    return "第一个参数是：" & (item 1 of argv)
end run
```

```bash
osascript hello.applescript 张三 李四
# → 第一个参数是：张三
```

⚠️ 所有参数都是 text 类型，要当数字用必须显式转换：`set n to (item 1 of argv) as integer`。

## 1.5 shell 引号地狱

AppleScript 用双引号，shell 也用引号，两者叠加极易出错。三条实用规则：

```bash
# 规则 1：外层用单引号，内层 AppleScript 的双引号就不用转义
osascript -e 'display dialog "你好"'

# 规则 2：AppleScript 字符串里需要单引号时，用 '\'' 跳出
osascript -e 'return "it'\''s ok"'

# 规则 3：内容复杂就写文件，别硬塞 -e
osascript ./myscript.applescript
```

从 shell 变量注入 AppleScript 字符串，**永远用 `quoted form of` 的思路**，不要手工拼：

```bash
NAME="O'Brien"
osascript - "$NAME" <<'EOF'
on run argv
    return "你好，" & (item 1 of argv)
end run
EOF
```

## 1.6 输出与返回值

`osascript` 打印脚本最后一个表达式的值（或 `return` 的值）。两个有用的开关：

```bash
osascript -s s -e 'return {"a", {"b"}}'   # recompilable 形式：{"a", {"b"}}
osascript -s h -e 'return {"a", {"b"}}'   # human 形式（默认）：a, b   ← 有歧义！
```

⚠️ 默认的人类可读输出会把 `{"foo","bar"}` 和 `{{"foo",{"bar"}}}` 都打印成 `foo, bar`。
需要在 shell 里可靠解析结果时，加 `-s s`，或者干脆让脚本输出 JSON（见 `docs/12-Shell互操作.md`）。

把错误输出到 stderr（默认行为），配合退出码判断成败：

```bash
if osascript myscript.applescript; then echo "成功"; else echo "失败"; fi
```

⚠️ **`osascript` 的 `-e` 模式下，错误位置是「拼接后源码的绝对字符偏移」，不是行列号。**
看到 `9:21: syntax error` 却找不到第 9 行，就是这个原因。用脚本文件（`.applescript`）跑，错误信息才会给出行号。

## 1.7 Script Editor 使用要点

| 快捷键 | 作用 |
| --- | --- |
| ⌘K | 编译（只做语法检查，不执行） |
| ⌘R | 运行 |
| ⌘. | 中断运行 |
| ⇧⌘O | 打开字典（查某个 App 的命令） |
| ⌥⌘K | 格式化/美化选中的代码 |

实用技巧：

- **结果窗格**：选中一行代码再按 ⌘R，只执行选中部分，方便调试。
- **事件日志**（菜单 显示 → 事件日志，⇧⌘2）：显示脚本发出的每一个 Apple Event 及返回值，排查「App 不听话」时极其有用。
- **字典**：左侧选 App，右侧看它的 class / command / property。这是写自动化脚本的**唯一权威依据**，不要靠猜。

## 1.8 用 sdef 在命令行查字典

不想开 GUI 时，`sdef` 直接把术语字典导出成 XML：

```bash
# Safari 支持哪些命令？
sdef /Applications/Safari.app | grep -oE '<command name="[^"]+"'

# Standard Additions 的全部命令
sdef /System/Library/ScriptingAdditions/StandardAdditions.osax \
  | grep -oE '<command name="[^"]+"'

# 看某个命令的完整定义（含参数）
sdef /Applications/Safari.app | grep -A8 '<command name="do JavaScript"'
```

常用路径：

```
/System/Library/ScriptingAdditions/StandardAdditions.osax   # current date、do shell script、display dialog 等
/System/Library/CoreServices/System Events.app              # 进程、窗口、UI 元素
/System/Library/CoreServices/Finder.app                     # 文件、文件夹、磁盘
/System/Applications/Mail.app                               # 邮件
/Applications/Safari.app                                    # Safari（注意不在 /System/Applications）
```

## 1.9 什么时候不该用 AppleScript

| 场景 | 更好的选择 |
| --- | --- |
| 纯文本处理、算法密集 | Python / shell |
| 只调用命令行工具 | shell 脚本 |
| 复杂 JSON / HTTP API | Python，或 JXA（JavaScript for Automation） |
| 需要跨平台 | Python |
| **控制 macOS 原生 App、UI 自动化、系统级操作** | **AppleScript（无可替代）** |

实践中最常见的组合是：**AppleScript 负责「和 App 说话」，`do shell script` 负责「和 Unix 说话」**。
见 `docs/12-Shell互操作.md`。
