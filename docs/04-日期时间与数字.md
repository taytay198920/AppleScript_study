# 04 日期、时间与数字

## 4.1 拿到当前时间

```applescript
set now to current date
```

⚠️ `current date` 来自 **Standard Additions**，不是核心语言。
一旦脚本里写了 `use framework "..."`，就必须补一行 `use scripting additions`，否则会编译报错。
详见 `docs/16-常见坑与排错.md`。

## 4.2 date 对象的属性

```applescript
set d to current date

year of d        --> 2026        (integer)
month of d       --> November    (month 枚举)
day of d         --> 16          (integer)
weekday of d     --> Monday      (weekday 枚举)
hours of d       --> 22          (integer)
minutes of d     --> 55          (integer)
seconds of d     --> 46          (integer)
time of d        --> 82546       (当天已过的秒数，integer)
date string of d --> "2026年11月16日"  （依赖系统区域设置）
time string of d --> "22:55:46"
d as string      --> "Monday, November 16, 2026 at 10:55:46 PM"（依赖区域设置）
```

⚠️ `month` 和 `weekday` 返回的是**枚举常量**，不是数字也不是字符串。
要数字必须显式转换：

```applescript
(month of d) as integer      --> 11
(weekday of d) as integer    --> 2（Sunday=1, Monday=2, …）
```

⚠️ `date string` / `time string` / `as string` 的输出格式**完全跟随系统区域设置**。
写自动化脚本时千万别拿它们去做数据交换，格式化请用 `NSDateFormatter`（见 4.6）。

## 4.3 日期运算

AppleScript 的日期加减直接用秒数常量：

| 常量 | 秒数 |
| --- | --- |
| `minutes` | 60 |
| `hours` | 3600 |
| `days` | 86400 |
| `weeks` | 604800 |

```applescript
set d to current date
set tomorrow to d + (1 * days)
set tenMinutesAgo to d - (10 * minutes)
set inThreeHours to d + (3 * hours)
```

两个 date 相减得到**秒数**（integer）：

```applescript
set elapsed to (current date) - startTime       --> 秒
set elapsedHours to elapsed / hours            --> 小时（real）
set elapsedHoursInt to elapsed div hours       --> 小时（integer，截断）
```

⚠️ 加 `days` 会自动处理跨月、跨年、夏令时。

## 4.4 构造指定日期

### 方式一：改 `current date`（可靠，推荐）

```applescript
set d to current date
set year of d to 2027
set month of d to January        -- 或 1
set day of d to 1
set time of d to 0               -- 当天 00:00:00
```

⚠️⚠️ **必须按 year → month → day 的顺序设置**。
如果今天是 1 月 31 日，先设 `month` 为 2 月会溢出成 3 月 3 日。
更安全的做法是先把 `day` 设成 1：

```applescript
set d to current date
set day of d to 1          -- 先归位，避免溢出
set year of d to 2028
set month of d to 2
set day of d to 29         -- 再设目标日
set time of d to (8 * hours + 30 * minutes)   -- 08:30:00
```

实测：把年份写成 **2027**（非闰年）而日期写 29，结果会得到 `March 1, 2027` —— 溢出自动进位，不会报错。
构造日期后建议校验一次 `day of d` 是否等于预期值。

「今天零点」「本月第一天」这类常用值：

```applescript
on startOfDay(theDate)
	copy theDate to t        -- ⚠️ 必须 copy，见下
	set time of t to 0
	return t
end startOfDay

on endOfDay(theDate)
	copy theDate to t
	set time of t to (24 * hours - 1)
	return t
end endOfDay

on startOfMonth(theDate)
	set t to my startOfDay(theDate)
	copy t to u
	set day of u to 1
	return u
end startOfMonth
```

⚠️⚠️ **`date` 是引用类型，handler 参数也是按引用传递的。** 实测如果写成 `set t to theDate`，
函数内 `set time of t to 0` 会把**调用方的那个日期变量一起改掉**。
必须用 `copy theDate to t`。详见 `docs/02-语言核心.md` §2.5。

月份/星期的常量名：

```
January February March April May June July August September October November December
Sunday Monday Tuesday Wednesday Thursday Friday Saturday
```

### 方式二：`date "字符串"`（⚠️ 不推荐）

```applescript
set d to date "2026-11-16 08:30:00"
set d to date "Monday, November 16, 2026 at 10:55:46 PM"
```

⚠️ 字符串格式**完全依赖系统区域设置**。同一份脚本在中文系统和英文系统上，
`date "11/16/2026"` 可能被解析成 11 月 16 日，也可能直接报错。
生产脚本请用 `NSDateFormatter`（4.6）。

## 4.5 时间戳

### 取当前 Unix 时间戳

```applescript
-- 最简单可靠
set unixTs to (do shell script "date +%s") as integer
```

### AppleScript date ↔ NSDate

⚠️ AppleScript 的 `date` **可以直接传给 ObjC 方法**，会自动桥接（实测）：

```applescript
use framework "Foundation"
use scripting additions

set d to current date
set theFormatter to current application's NSDateFormatter's new()
theFormatter's setLocale:(current application's NSLocale's localeWithLocaleIdentifier:"en_US_POSIX")
theFormatter's setDateFormat:"yyyy-MM-dd HH:mm:ss"
set s to (theFormatter's stringFromDate:d) as text     --> "2026-11-16 22:58:51"  ✅
```

⚠️ **不要用「参考日期差值」手工换算**。实测 `d - (date "Monday, January 1, 2001 at 12:00:00 AM")`
得到的结果会偏差若干小时（本地时区 vs UTC 基准），格式化后时间直接错掉。
直接桥接（如上）才是正确做法。

### 字符串 → 日期

```applescript
use framework "Foundation"
use scripting additions

on parseDate(dateString, formatString)
	set theFormatter to current application's NSDateFormatter's new()
	theFormatter's setLocale:(current application's NSLocale's localeWithLocaleIdentifier:"en_US_POSIX")
	theFormatter's setDateFormat:formatString
	set theDate to theFormatter's dateFromString:dateString
	if theDate is missing value then error "无法解析日期：" & dateString
	return theDate
end parseDate

-- parseDate("2026-11-16", "yyyy-MM-dd")
```

## 4.6 格式化（推荐方案）

```applescript
use framework "Foundation"
use scripting additions

property dateFormatter : missing value

on formatDate(theDate, formatString)
	if my dateFormatter is missing value then
		set my dateFormatter to current application's NSDateFormatter's new()
		my dateFormatter's setLocale:(current application's NSLocale's localeWithLocaleIdentifier:"en_US_POSIX")
	end if
	my dateFormatter's setDateFormat:formatString
	return (my dateFormatter's stringFromDate:theDate) as text
end formatDate

-- formatDate(current date, "yyyy-MM-dd")             --> "2026-11-16"
-- formatDate(current date, "yyyy年MM月dd日 HH:mm")    --> "2026年11月16日 22:58"
-- formatDate(current date, "yyyyMMdd-HHmmss")        --> 适合做文件名
```

⚠️ 一定要 `setLocale:` 为 `en_US_POSIX`，否则某些区域设置下 `yyyy` 会得到非公历年份。

### 纯 AppleScript 的简易格式化（无依赖）

```applescript
on padLeft(n, width)
	set s to (n as integer) as text
	repeat while (length of s) < width
		set s to "0" & s
	end repeat
	return s
end padLeft

on simpleStamp(d)
	return (year of d as text) & "-" & my padLeft(month of d, 2) & "-" & my padLeft(day of d, 2) ¬
		& " " & my padLeft(hours of d, 2) & ":" & my padLeft(minutes of d, 2) & ":" & my padLeft(seconds of d, 2)
end simpleStamp

-- simpleStamp(current date) --> "2026-11-16 22:58:51"
```

⚠️ `padLeft(month of d, 2)` 里 `month of d` 是枚举，`as integer` 会自动转成 1–12，实测可用。

## 4.7 数字处理

### round（Standard Additions）

⚠️⚠️ **`round` 只能舍入到整数，没有 `round x to n` 这种语法。**
官方 sdef 定义：直接参数是一个 real，可选参数只有 `rounding`，**返回值类型固定是 integer**。
实测 `round 3.14159 to 2` 会直接编译报错 `A "to" can't go after this real number (-2740)`。

```applescript
round 3.2                                --> 3
round 3.7                                --> 4
round 3.7 rounding down                  --> 3
round 3.2 rounding up                    --> 4
round -3.7 rounding toward zero          --> -3
round 2.5                                --> 2   ⚠️ 银行家舍入
round 3.5                                --> 4   ⚠️ 银行家舍入
round 2.5 rounding as taught in school   --> 3   ✅ 真正的四舍五入
round 2.5 rounding to nearest            --> 2   （= 默认行为）
```

⚠️ 默认模式对 `.5` 采用**银行家舍入**（舍入到最近的偶数），官方文档原话：
> "to nearest" rounds .5 cases to the nearest even integer in order to decrease cumulative errors.
> To always round .5 away from zero, use "as taught in school."

### 保留 N 位小数（自己实现）

```applescript
on roundTo(x, places)
	set factor to 10 ^ places
	return (round (x * factor) rounding as taught in school) / factor
end roundTo

-- roundTo(3.14159, 2)   --> 3.14
-- roundTo(3.7, 0)       --> 4.0    ⚠️ 返回 real 不是 integer
-- roundTo(-2.5, 0)      --> -3.0
```

### 取整（截断，非四舍五入）

```applescript
3.7 as integer        --> 4   ⚠️ as integer 是四舍五入，不是截断！
```

要真正的截断，用 `rounding toward zero`：

```applescript
round 3.7 rounding toward zero     --> 3
round -3.7 rounding toward zero    --> -3
```

### 随机数

```applescript
random number                       --> 1 到 2^31-1 的整数
random number from 1 to 10          --> 1..10
random number from 1.0 to 2.0       --> 实数
```

### 格式化数字（千分位、固定小数）

AppleScript 没有 `printf`，用 `NSNumberFormatter`：

```applescript
use framework "Foundation"
use scripting additions

on formatNumber(theNumber, decimals)
	set theFormatter to current application's NSNumberFormatter's new()
	theFormatter's setNumberStyle:(current application's NSNumberFormatterDecimalStyle)
	theFormatter's setMinimumFractionDigits:decimals
	theFormatter's setMaximumFractionDigits:decimals
	theFormatter's setLocale:(current application's NSLocale's localeWithLocaleIdentifier:"zh_CN")
	return (theFormatter's stringFromNumber:theNumber) as text
end formatNumber

-- formatNumber(1234567.891, 2)  --> "1,234,567.89"
```

### 整型溢出

⚠️ AppleScript 的 `integer` 是 64 位，但**算术中间结果可能溢出成实数或报错**。
处理大数（如毫秒时间戳）时建议用 `do shell script` 或 AppleScriptObjC 的 `NSNumber`。
