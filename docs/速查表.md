# AppleScript 速查表

一页纸常用语法。详细说明见对应章节。

---

## 变量与类型

```applescript
set x to 5                        -- 赋值
x is 5                            -- 比较
class of x                        --> integer
x as text                         --> "5"
set y to missing value            -- 空值
```

| 类型 | 示例 | class of |
| --- | --- | --- |
| 整数 | `42` | `integer` |
| 实数 | `3.14` | `real` |
| 文本 | `"a"` | `text` |
| 布尔 | `true` | `boolean` |
| 列表 | `{1,2}` | `list` |
| 记录 | `{a:1}` | `record` |
| 日期 | `current date` | `date` |

⚠️ **`set` 是共享引用**（list / record / date），要副本用 `copy a to b`。

## 常量

```
true  false  missing value  pi
linefeed (\n, id 10)   return (\r, id 13)   tab (\t, id 9)   space   quote (")
minutes(60)  hours(3600)  days(86400)  weeks(604800)
January…December   Sunday…Saturday
```

⚠️ AppleScript **没有 null**，用 `missing value`。

## 运算符

```applescript …
+  -  *  /            -- / 永远返回 real
div  mod  ^           -- 7 div 2 → 3；7 mod 2 → 1；2^10 → 1024.0
=  ≠  <  >  ≤  ≥
and  or  not          -- 短路求值
&                     -- 拼接，结果类型由左操作数决定
```

```applescript
x is in {1,2,3}          -- 成员
s contains "ab"          -- 包含
s starts with "A"
s ends with "z"
```

⚠️ `if` 的条件**必须是 boolean**：`if 0 then` 会报 -1700。

⚠️ 连续 `as` 要加括号：`((x as integer) as text)`。

## 列表

```applescript
set l to {1, 2, 3}
item 1 of l              --> 1        （索引从 1 开始）
item -1 of l             --> 3
first item of l  /  last item of l
items 2 thru 3 of l      --> {2, 3}   （闭区间）
items 1 thru -2 of l     --> {1, 2}   （去掉最后一个）
rest of l                --> {2, 3}
count of l               --> 3
l contains 2             --> true
reverse of l             --> {3, 2, 1}

set end of l to 4        -- 追加（快）
set beginning of l to 0  -- 前插（慢）
set item 2 of l to 99    -- 改
delete item 2 of l       -- 删
l & {5, 6}               -- 拼接
```

⚠️ `butlast` **不可用**，用 `items 1 thru -2 of l`。
⚠️ `repeat with x in l` 里 `x` 是引用，取值用 `contents of x`，改原列表用 `set contents of x to …`。

## 记录

```applescript
set r to {name:"A", age:3}
name of r      /   r's age
count of r              --> 2
{a:1} & {b:2}           --> {a:1, b:2}
{a:1, b:9} & {a:5}      --> {a:1, b:9}   ⚠️ 同名字段左边优先
```

⚠️ 键名避开 `name`、`id`、`class`、`text`、`URL`（桥接 NSDictionary 时会丢）。
⚠️ 不能用变量当键名；要动态取键走 AppleScriptObjC。

## 文本

```applescript
set s to "AppleScript"
length of s              --> 11
text 1 thru 5 of s       --> "Apple"    （闭区间）
text 7 thru -1 of s      --> "cript"
character 3 of s
first character of s  /  last character of s

offset of "Scr" in s     --> 6（找不到返回 0）
quoted form of s         --> 用于 shell
id of "A"                --> 65
character id 65          --> "A"
characters of s          --> {"A","p",…}
```

### 切分 / 拼接（全局状态，务必还原）

```applescript
set oldDelims to AppleScript's text item delimiters
set AppleScript's text item delimiters to ","
set parts to text items of "a,b,c"        -- 切分 → {"a","b","c"}
set joined to parts as text               -- 拼接 → "a,b,c"
set AppleScript's text item delimiters to oldDelims
```

⚠️ 没有内置 upper/lower，用 `NSString's uppercaseString()` 或 shell `tr`。
⚠️ 没有 printf，补零自己写（见 §3.7）。

## 日期

```applescript …
set d to current date
year of d  month of d  day of d  weekday of d
hours of d  minutes of d  seconds of d  time of d
(month of d) as integer          --> 11

d + (1 * days)    d - (90 * minutes)
(d2 - d1)                        --> 秒数(integer)

set year of d to 2027            -- 改
set time of d to 0               -- 当天零点
set time of d to (8 * hours + 30 * minutes)
```

⚠️ 改日期顺序：先 `set day to 1`，再 year → month → day，否则溢出。
⚠️ `date "字符串"` 依赖区域设置，别用。格式化用 `NSDateFormatter`（§4.6）。
⚠️ handler 里要 `copy theDate to t`，否则改到调用方的变量。

## 数字

```applescript
round 3.2                                --> 3
round 3.7 rounding down                  --> 3
round 3.2 rounding up                    --> 4
round -3.7 rounding toward zero          --> -3
round 2.5 rounding as taught in school   --> 3   （真四舍五入）
round 2.5                                --> 2   ⚠️ 银行家舍入
3.7 as integer                           --> 4   ⚠️ 四舍五入，非截断
```

## 函数

```applescript …
on add(a, b)
	return a + b
end add

my add(1, 2)                -- ⚠️ handler 内调用必须加 my

on run argv                 -- argv 是命令行参数列表
on open droppedItems        -- droplet 拖放
on idle                     -- stay-open，返回下次间隔秒数
on quit                     -- 必须写 continue quit
```

⚠️ **只支持位置参数**，没有具名参数。用记录传：

```applescript
on f(opts)
	set merged to opts & {level:1, verbose:false}   -- opts 在前！
end f
my f({level:5})
```

⚠️ 可选参数手动实现：`if y is missing value then set y to 100`。

## 错误处理

```applescript
try
	…
on error errMsg number errNum from errFrom to errTo
	if errNum is -128 then return          -- 放行"用户取消"
	error errMsg number errNum             -- 重新抛出
end try

error "消息" number 5000
```

| 码 | 含义 |
| --- | --- |
| -128 | 用户取消 |
| -1700 | 类型转换失败 |
| -1708 | 不理解该消息（术语解析 / 拼错） |
| -1712 | 超时 |
| -1727 | Expected a reference（Finder count） |
| -1728 | Can't get（文件不存在 / butlast） |
| -1743 | 自动化权限被拒 |
| -25211 | 辅助功能权限缺失 |
| -43 | 文件未找到 |
| -2740/-2741 | 编译期语法错误 |

## tell 与术语

```applescript
tell application "Finder"
	…
end tell

tell application "Finder" to count of files of desktop    -- 单行

using terms from application "Finder"     -- 只借术语，不启动 App
	…
end using terms from

with timeout of 300 seconds               -- 只对 Apple Event 生效
	…
end timeout

ignoring application responses            -- 不等回复
	…
end ignoring
```

⚠️ **在 tell 块里，给自己的 handler / Standard Additions 命令 / 顶层 property 加 `my`。**

⚠️ `with timeout` 管不到 `delay` 和本地循环。

## 路径

```applescript
POSIX file "/tmp/a.txt"                 -- → file（文件可不存在）
POSIX file "/tmp/a.txt" as alias        -- → alias（⚠️ 必须已存在）
POSIX path of someAlias                 -- → "/tmp/a.txt"
someAlias as text                       -- → "Macintosh HD:private:tmp:a.txt"

path to home folder / desktop folder / documents folder / downloads folder
path to temporary items / preferences folder / scripts folder
path to application support folder from user domain
path to me                              -- 当前脚本
path to application "Safari"
```

⚠️ 给 Finder 的路径用 `/private/tmp/...`，不要用 `/tmp/...`（符号链接会导致 -43）。

## 文件 I/O

```applescript
-- 写
set fh to open for access (POSIX file p) with write permission
set eof of fh to 0                                  -- 清空（追加则省略）
write theText to fh starting at eof as «class utf8»
close access fh

-- 读全文
set txt to read (POSIX file p) as «class utf8»

-- 按行读（返回 list）
set fh to open for access (POSIX file p)
set lines to read fh using delimiter linefeed
close access fh

-- 读片段
read fh from 1 for 100
```

⚠️ 三必守：`close access` / `as «class utf8»` / 用 `linefeed`。
⚠️ 判断文件是否存在（**别用** `System Events` 的 `exists file`，查不存在的文件且在
`~/Desktop` 等 TCC 保护目录里会无限挂起并卡死 System Events，见 `docs/09-Finder与文件读写.md` §9.5）：

```applescript
on fileExists(posixPath)
	try
		return (do shell script "test -f " & quoted form of posixPath & " && echo yes || echo no") is "yes"
	on error
		return false
	end try
end fileExists
```

## Shell

```applescript
do shell script "ls -la"
do shell script "cmd " & quoted form of userPath           -- ⚠️ 必须 quoted form of
do shell script "cmd" altering line endings false          -- 保留 LF
do shell script "cmd 2>&1"                                 -- 捕获 stderr
do shell script "cmd || true"                              -- 忽略非零退出码
do shell script "cmd" with administrator privileges        -- 弹密码框
do shell script "/bin/zsh -lc " & quoted form of "cmd"     -- 用 zsh + 完整 PATH
```

⚠️ 默认是 `/bin/sh`（不是 zsh/bash），PATH 极简，stderr 被丢弃，退出码非 0 → 抛错（错误号 = 退出码）。
⚠️ 输出的 `\n` 会被转成 `\r`，除非 `altering line endings false`。

## 对话框

```applescript
display dialog "文字" buttons {"取消","好"} default button "好" cancel button "取消" ¬
	with title "标题" with icon caution giving up after 10
--> {button returned:"好", gave up:false}

display dialog "输入" default answer "" hidden answer true
--> {button returned:"好", text returned:"…", gave up:false}

display alert "标题" message "详情" as warning buttons {"好"}
display notification "正文" with title "标题" subtitle "副标题" sound name "Glass"

choose file with prompt "…" of type {"public.image"} with multiple selections allowed
choose folder with prompt "…" default location (path to desktop folder)
choose file name with prompt "…" default name "a.txt"     --> file（可不存在）
choose from list {"a","b"} with prompt "…" default items {"a"}
```

⚠️ `giving up after 0` = **永不超时**（会阻塞）。
⚠️ 取消：`display dialog`/`choose *` 抛 **-128**；`choose from list` 返回 **false**。
⚠️ `choose *` 无超时参数，**定时任务里绝不能用**。

## AppleScriptObjC

```applescript
use framework "Foundation"
use scripting additions          -- ⚠️ 必加

-- 大小写
((current application's NSString's stringWithString:s)'s uppercaseString()) as text

-- 日期格式化
set fmt to current application's NSDateFormatter's new()
fmt's setLocale:(current application's NSLocale's localeWithLocaleIdentifier:"en_US_POSIX")
fmt's setDateFormat:"yyyy-MM-dd HH:mm:ss"
(fmt's stringFromDate:(current date)) as text      -- AppleScript date 自动桥接

-- 记录取键
set theDict to current application's NSDictionary's dictionaryWithDictionary:rec
(theDict's allKeys()) as list

-- 排序
set theArray to current application's NSArray's arrayWithArray:lst
set theDesc to current application's NSSortDescriptor's sortDescriptorWithKey:"mySize" ascending:true
(theArray's sortedArrayUsingDescriptors:{theDesc}) as list

-- 高精度计时
set t to (current application's NSDate's |date|())
```

⚠️ ObjC 方法名结尾的 `_` 在 AppleScript 里写成 `:`；无参方法要加 `()`：`|date|()`。
⚠️ ObjC 保留字用竖线包起来：`|date|`、`|class|`、`|count|`、`|description|`。
⚠️ **变量名不要叫 `nsArray`/`nsString`/`nsDate`**（大小写不敏感会撞类名）。

⚠️ **这些名字一律不能当变量**（实测，详见 §2.9）：

```applescript …
st  nd  rd  th         -- 序数后缀，-2741 Expected expression but found "st"
line  text  item       -- 文本元素类名，-10003 Access not allowed
it  its  me            -- 指向当前脚本，只读
lines  words  paragraphs  characters  items   -- 运行期 -10006 Can't set every line to …
name  id  key  log     -- 标准属性名 / 命令名
result                 -- 能赋值，但每条语句后被静默覆盖（§16.2⑳）
```

循环变量也别用 `line`：`repeat with line in …` 直接编译失败，改 `repeat with ln in …`。

## 命令行

```bash
osascript -e 'return 1+1'                    # 单行
osascript -e 'set x to 1' -e 'return x'      # 多行（⚠️ 中间的 return 会终止）
osascript script.applescript arg1 arg2       # 传参 → on run argv
echo 'return "x"' | osascript -              # stdin
osascript -s s -e 'return {"a",{"b"}}'       # 无歧义输出
osascript -l JavaScript -e '…'               # JXA

osacompile -o x.scpt x.applescript           # 编译
osacompile -s -o X.app x.applescript         # stay-open applet
osacompile -x -o x.scpt x.applescript        # execute-only
osadecompile x.scpt                          # 反编译

sdef /Applications/Safari.app                # 查 App 字典
osalang                                      # 列出脚本语言

launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/x.plist
launchctl kickstart -k gui/$(id -u)/com.example.x
tccutil reset AppleEvents com.apple.Terminal
```

## 高危写法自查清单

- [ ] `text item delimiters` 用完还原了吗？
- [ ] `open for access` 都有配对的 `close access`（含出错分支）吗？
- [ ] `use framework` 后面有 `use scripting additions` 吗？
- [ ] `tell` 块里的自定义 handler 都加 `my` 了吗？
- [ ] `set b to a` 之后改 `b`，`a` 会不会被连带改掉？
- [ ] 用户点「取消」（-128）的路径处理了吗？
- [ ] 定时任务里有没有会永久阻塞的对话框？
- [ ] shell 命令里的变量都过 `quoted form of` 了吗？
- [ ] `if` 的条件真的是 boolean 吗（不是 0 / "" / {}）？
- [ ] 变量名有没有撞关键字（尤其 `nd`/`st`/`line`）或 ObjC 类名？
